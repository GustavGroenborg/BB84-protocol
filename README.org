* BB84 Protocol Implementation

This repository contains a Python implementation of the BB84 Quantum Key
Distribution (QKD) protocol. It supports running simulations locally, with or
without noise models, and executing circuits on real IBM Quantum hardware. I have enclosed the
[[./quantum-key-distribution.pdf][report]] that I wrote along with implementing the CLI of this repository. Please
note that the below documentation was generated by Google Gemini, and published,
after I had defended my work at the exam.

** Installation
:PROPERTIES:

:END:

uv sync

pip install -r requirements.txt  # If requirements.txt is provided, otherwise use uv

** Environment Variables
:PROPERTIES:
:CUSTOM_ID: environment-variables
:END:

When running on real quantum hardware (~--online~), the following environment variables are required. You can define them in a ~.env~ file in the root directory.

| Variable    | Description                                                  |
|-------------+--------------------------------------------------------------|
| ~IBM_TOKEN~ | Your IBM Quantum API token.                                  |
| ~CRN~       | The Cloud Resource Name (CRN) for your IBM Quantum instance. |

** Usage
:PROPERTIES:
:CUSTOM_ID: usage
:END:

*** Basic Simulation
:PROPERTIES:
:CUSTOM_ID: basic-simulation
:END:

Run a simple noiseless simulation with a default key length of 6:

#+BEGIN_SRC bash
python main.py --noiseless
#+END_SRC

Run a noisy simulation (simulating ~ibm_fez~ characteristics):

#+BEGIN_SRC bash
python main.py
#+END_SRC

Run with an eavesdropper (Eve):

#+BEGIN_SRC bash
python main.py --with-eve
#+END_SRC

*** Running on IBM Quantum
:PROPERTIES:
:CUSTOM_ID: running-on-ibm-quantum
:END:

To run the protocol on real hardware, ensure your environment variables are set and use the ~--online~ flag:

#+BEGIN_SRC bash
python main.py --online --qpu ibm_fez
#+END_SRC

*** CLI Flags
:PROPERTIES:
:CUSTOM_ID: cli-flags
:END:

| Flag             | Type     | Default   | Description                                              |
|------------------+----------+-----------+----------------------------------------------------------|
| ~--ibm-token~    | ~str~    | ~None~    | IBM Quantum API token. (Overrides ~IBM_TOKEN~ env var).  |
| ~--crn~          | ~str~    | ~None~    | IBM Quantum CRN. (Overrides ~CRN~ env var).              |
| ~--qpu~          | ~choice~ | ~ibm_fez~ | The QPU to use (~ibm_kingston~, ~ibm_fez~, ~ibm_marrakesh~). |
| ~--key-length~   | ~int~    | ~6~       | Desired length of the final secret key.                  |
| ~--results-path~ | ~str~    | ~None~    | Path to save the results in JSON format.                 |
| ~--test-name~    | ~str~    | ~None~    | Name of the test (required if ~--results-path~ is used). |
| ~--repeat~       | ~int~    | ~1~       | Number of times to repeat the execution.                 |
| ~--with-eve~     | ~bool~   | ~False~   | Enable eavesdropping by Eve.                             |
| ~--online~       | ~bool~   | ~False~   | Run on real IBM Quantum hardware.                        |
| ~--noiseless~    | ~bool~   | ~False~   | Run the simulator without a noise model.                 |
| ~-O-1~           | ~flag~   | -         | No optimization or transpilation (requires ~--noiseless~). |
| ~-O0~            | ~flag~   | Default   | No optimization, transpilation only.                     |
| ~-O1~            | ~flag~   | -         | Light optimization.                                      |
| ~-O2~            | ~flag~   | -         | Medium optimization.                                     |
| ~-O3~            | ~flag~   | -         | High optimization.                                       |

** Results
:PROPERTIES:
:CUSTOM_ID: results
:END:

Results are saved as a JSON array. Each entry includes:
- Test name and timestamp.
- Number of qubits used.
- Key length and optimization level.
- Fidelity and loss between Alice/Bob (and Eve if present).
- Final keys, bases, and bits for each participant.

Example results can be found in the ~results/~ directory.
